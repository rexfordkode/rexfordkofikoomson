## ⚡ Quick Start

Run instantly in any terminal with `npx` (zero installation required):

```sh
# Launch the interactive Antigravity / Gemini TUI Console
npx rexford

# Launch the interactive Curriculum Vitae Tab Explorer
npx rexford-cv

# Direct static card mode (for pipes, scripts, or quick glance)
npx rexford --static
npx rexford-cv --static
```

Or install globally:

```sh
npm install -g rexford
rexford
rexford-cv
```

## ✨ Antigravity & Gemini Terminal Features

### 1. `npx rexford` — Interactive Operator Dashboard
- ✦ **Live Network Telemetry Probe**: Asynchronously checks [rexfordkofikoomson.me](https://rexfordkofikoomson.me) in the background to report real-time live latency, HTTP response status, and TLS 1.3 handshake.
- ✦ **Interactive Fullscreen TUI Console**: Runs in an alternate screen buffer (`xterm-alt-screen`) with auto-resize handling (`process.stdout.on('resize')`).
- ✦ **Hybrid Gemini AI Agent (`[1]`)**:
  - **Offline Mode:** Built-in streaming intelligence engine answering questions about Rexford's experience, system architecture, GVSU M.Sc., and tech stack.
  - **Live Mode:** Automatically connects to Google's **Gemini 2.0 Flash** API if `GEMINI_API_KEY` is present in your environment for open-ended conversation.
- ✦ **Direct Hotkeys**:
  - `[o]`: Automatically launches **[rexfordkofikoomson.me](https://rexfordkofikoomson.me)** in your default browser.
  - `[c]`: Instantly copies Rexford's email (`rexford.kk@gmail.com`) to your OS clipboard.
  - `[m]`: Triggers the **Antigravity Quantum Mesh / Matrix Rain** easter egg.
  - `[q]`: Safely exits and restores terminal state.

### 2. `npx rexford-cv` — Interactive CV Explorer
- ✦ **Tabbed Navigation**: Switch smoothly across `[1] Overview`, `[2] Experience`, `[3] Architecture`, `[4] Education`, and `[5] Skills Matrix` using `← / →`, `h / l`, or number keys `1–5`.
- ✦ **One-Click Markdown Export (`[e]`)**: Instantly exports a clean, professional `REXFORD_KOOMSON_CV.md` file directly into your current directory.
- ✦ **Architectural Deep-Dive**: Details high-throughput telemetry pipelines (Heatmap), ERP microservice meshes (AmaliTech), and cloud deployments.
- ✦ **Static Mode Support**: Run `npx rexford-cv --static` to stream clean plain text suitable for piping (`| less`, `| cat`, or file redirection).
